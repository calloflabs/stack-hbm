# 🍉 HBM 수박게임 (HBM Suika)

수박 대신 웨이퍼. 중력 대신 스핀코터. 원형 챔버에 공정 조각을 떨어뜨리면 회전 때문에 가장자리로 밀리고 같은 조각끼리 부딪히면 다음 공정으로 넘어갑니다. 실리콘에서 시작해 12단 HBM까지 쌓으면 하이닉스에 갈 수 있을지도 모릅니다.

**연구실에서 살아남기 외전** ·

▶️ 플레이: https://stack-hbm.vercel.app · English: https://stack-hbm.vercel.app/?lang=en

## 조작

- 탭하면 테두리를 도는 로봇암에서 조각이 가운데로 들어갑니다.
- 길게 누르면 챔버가 돌아 조각이 바깥으로 퍼집니다. 왼쪽을 누르면 역회전. 손을 떼면 다시 가운데로 미끄러지며 부딪힙니다.
- 조각이 벽에 2초 넘게 눌리면 웨이퍼가 깨집니다. 빨간 원호가 다 차기 전에 회전을 멈추세요.

## 공정

실리콘 → 웨이퍼 → PR → 노광 → 식각 → 증착 → DRAM → TSV → 4단 → 8단 → 12단 HBM

12단 HBM 두 개가 만나면 출하됩니다. 게임은 끝나지 않으니 계속 만드세요.
